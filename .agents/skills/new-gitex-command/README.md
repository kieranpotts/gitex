# New GitEx command

Implement a new GitEx command from scratch, including tests and documentation.

## Interactivity

This skill is NOT intended to be used in away-from-keyboard agentic workflows.
The agent is instructed to prompt for anything it is unsure about, such as the
intended command name and its interface. The agent is explicitly instructed to
abort, rather than guess, if it considers any of the requirements to be vague
or incomplete.

## How to invoke

> Implement `git <command-name>`.

## Recommended models

Use a frontier model, with effort or thinking levels dialled up.
